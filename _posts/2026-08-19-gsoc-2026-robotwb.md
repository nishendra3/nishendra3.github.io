This summer I worked on the FreeCAD Google Summer of Code 2026 project
**"Reviving and modernising the Robotic Workbench" (350h)**, mentored by
Carlo Dormeletti ([onekk](https://github.com/onekk)). The project set out to
modernise FreeCAD's built-in Robot workbench, and along the way became
something bigger: **Robot WB**, a brand-new robot simulation workbench,
developed as an addon.

- Proposal: [Proposal Doc](https://docs.google.com/document/d/1P4ZzBfkvQmT7zVAlykTRpDF8nl5pz8L9hUQemLa8C_I/edit?usp=sharing)
- Code: [nishendra3/RobotWB](https://github.com/nishendra3/RobotWB)
  ([my commits](https://github.com/nishendra3/RobotWB/commits))
- Documentation: [project wiki](https://github.com/nishendra3/RobotWB/wiki)

## From the proposal to an addon

The proposal targeted the built-in `Mod/Robot` module: URDF import,
joint-space trajectory export, a KDL library refresh, and removing the
hard-coded 6-axis limit. The direction of the project however changed,
considering that now we have good kinematics support also in python. Keeping
the code in python would allow easier entry for new contributors and it
would also help us to clean the exisiting FreeCAD codebase of old library
that is no longer needed there. The goals in this new WB were the same: robots
of any DOF, easy robot definition, trajectory tooling with multi robot support.

## What the workbench does

You take an ordinary FreeCAD Assembly, run it through a wizard, and get a "robot"
object which you can pose with sliders, solve IK for by dragging its tool, and drive
along taught trajectories, all inside FreeCAD, without needing an external simulator.

## Features built over the summer

### Define Robot

A four-step wizard (import parts, insert them, define joints, review) that
converts an Assembly into a robot object. Joints get axes, limits, and
directions; the robot roots at an editable base frame so it can be placed
anywhere in the scene. Revolute and prismatic joints are supported as of now.

![Define Robot wizard](/assets/images/gsoc/define-robot.png)

### Trajectories

Waypoints can be taught and played back with point-to-point (PTP) and linear
(LIN) motion types, and a trajectory player syncs playback across multiple
robots.

![Trajectory teaching](/assets/images/gsoc/trajectory.png)

### Animate Robot

Per-joint sliders for forward-kinematic posing, with live joint-limit
enforcement and joint markers in the 3D view.

![Animate Robot panel](/assets/images/gsoc/animate-robot.png)

### Define Tool and inverse kinematics

A tool can be attached to the flange with a configurable TCP. Dragging the TCP
solves IK and poses the whole chain. The default solver is a damped-least-squares
backend; pinocchio, tesseract-robotics, and ikpy are optional alternatives.

![Define Tool](/assets/images/gsoc/define-tool.png)

### Multi-Robot Control

One panel to jog every robot in the document, which useful for cells with several
robots working together.


### Scripting API

Everything above is scriptable from Python: building robots, posing joints,
solving IK, and running trajectories without touching the GUI.

## State of the work

All six workbench features work today; development history is in
[my commits](https://github.com/nishendra3/RobotWB/commits)
(45+ commits, May–August 2026). Nothing is merged into FreeCAD itself yet,
the project moved to the addon path and is not yet mature enough for merge.
The route into users' hands is the FreeCAD Addon Manager:
**[draft Addon Manager PR — link to be added]**.

Left for after GSoC: Refining UI based on user-feedback, collision and
reachability envelopes, shared trajectories, multiple-tools per trajectory,
import of URDF files, export to vendor-specific formats

## Challenges and lessons

- It was my first large codebase. learning FreeCAD's App/Gui split, FeaturePython
  objects, and the new Assembly workbench internals.
- Pivoting from the proposal's patching the C++-module plan to designing a new
  workbench from scratch, with the scope decisions that came with it.
- Incorporation of the different UI changes based on user feedback provided
  useful insights.
